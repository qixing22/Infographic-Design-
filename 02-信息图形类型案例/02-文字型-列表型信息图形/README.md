# 文字型/列表型信息图形（Informational / List Infographics）

> 文档状态：已纳入 CASE-37 电气与电子电路符号图；后续按案例继续验证。

## 当前分析范围（待案例验证）
本类重点收集以文字信息、条目、清单、步骤、分类或简短说明为主要内容组织方式的信息图形。是否包含图标、数字、插画、统计图形，以及这些元素承担何种信息功能，均以具体案例为准。

## 案例分析维度
1. **内容单元**：标题、条目、段落、步骤、注释、标签等。
2. **组织逻辑**：列表顺序、分类分组、优先级、步骤流程、并列比较或索引关系。
3. **文字层级**：标题、分标题、正文、数字、注释的层级与阅读负荷。
4. **视觉编码**：编号、项目符号、图标、色彩、字体、字号、字重、间距、分栏和分组。
5. **信息架构**：内容如何拆分、归类、排序与建立关联。
6. **视觉叙事**：读者从哪里开始，如何扫描条目，如何识别重点并完成理解。

## 需要从案例中验证的问题
- 文字是主要信息载体，还是仅为图形的注释？
- 列表顺序由时间、重要性、空间、字母还是主题决定？
- 图标/符号是否具有明确语义，能否脱离文字独立识别？
- 版式如何在信息密度与可读性之间取得平衡？
