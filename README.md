## 风格克隆与主题改编

从案例确定数据逻辑、阶段或数值，再调用 [Style-Cloning-System 风格库](https://github.com/qixing22/Style-Cloning-System/tree/main/library)选择视觉规则。生成时保留案例的原始标签、单位和证据状态，按新主题调整构图与表现关系。

[CASE-17 跨仓库示例](https://github.com/qixing22/Style-Cloning-System/tree/main/integrations)读取本库固定版本的案例分析和 CSV，将六个可辨识阶段编译为四版提示词。这个案例的数据只支持顺序表达，图中各阶段使用等体量模块。

每例按主导数据关系确定一个基础逻辑。表现标签用于按图形形式浏览，辅助标签记录在案例报告中。
