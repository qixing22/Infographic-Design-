# 05 叙事框架搭建

用能回答同一阅读问题的数据列搭建一个叙事单元。为每个单元记录阅读问题、所需字段和预期表达。

| 阅读问题 | 数据列组合 | 叙事单元 |
| --- | --- | --- |
| 各地点在哪里？ | 地点名称 + 经度 + 纬度 | 地图上的地点及其标签 |
| 同一年各地 GDP 如何比较？ | 地点名称 + GDP 数值，筛选到同一统计年份和口径 | 各地 GDP 的对比 |

将叙事单元排成阅读顺序，并明确每一部分的标题。
