第三批18张信息图原图上传说明

目标仓库：https://github.com/qixing22/Infographic-Design-

本压缩包中的目录已经按仓库当前的表现标签目录和 CASE 编号建立。
每张图片都保留用户上传时的原始文件名和图像内容，未裁切、未压缩、未重绘。

上传步骤：
1. 解压本 ZIP。
2. 打开 GitHub 仓库首页。
3. 点击 Add file（添加文件）→ Upload files（上传文件）。
4. 将解压后得到的“02-信息图形类型案例”文件夹拖入上传区域。
5. 等待上传列表全部加载。
6. 提交说明填写：补充 CASE-41 至 CASE-58 原始图片。
7. 点击 Commit changes（提交更改）。

上传后，每张原图会在对应 CASE 文件夹的“原图”子文件夹中。
请不要只上传归档清单 CSV；必须确认 JPG 文件本身出现在上传列表。
