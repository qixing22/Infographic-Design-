# 04 基础数据集构建

**每列只定义一个字段，每个单元格只存一个值。** 一行对应一个明确的观测对象或一条记录。字段可以是名义数据、量化数据、图片路径或文本。多个图片或文本记录有独立含义时，可用记录 ID 关联明细表。

| 字段示例 | 值示例 | 类型 |
| --- | --- | --- |
| 地点名称 | 杭州 | 名义 |
| 纬度 | 30.2741 | 量化 |
| 经度 | 120.1551 | 量化 |
| 图片路径 | images/hangzhou.jpg | 图像引用 |
| 地点说明 | 位于钱塘江下游 | 文本 |

数据字典记录字段名称、类型、单位、来源和缺失值约定。经度和纬度分列存储。
