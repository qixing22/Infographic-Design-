# 词云信息图（Word Cloud Infographics）

> 市场化表现形式标签，不是新增的基础类型。每件作品仍须从编年型、层级型、编目型、字母表型、地理图型中选择唯一主归属。

## 概念
将词语或短语排布为整体视觉图形，常以文字大小呈现词频或其他权重。

## 五大基础类型归属
按作品主导的数据/信息关系判断主归属，不依据外观、插画风格或统计图数量直接定类。可以记录辅助组织逻辑与其他表现标签。

## A｜基本数据逻辑
逐图识别最小记录单元、组织键、实体关系和字段。重点检查：标准化词项、词频/权重、语料来源、分词与去重规则。 未见原始数据时区分图面事实、合理推断与待确认信息。

## B｜统计图形与计算
区分词频、文档频次、相对频率和TF-IDF；字号不是精确面积比例。 记录图表名称、数据转换、统计口径、单位、分母和尺度；无数值统计时明确写“本例无须数值统计”，不得补造数值。

## C｜视觉编码
逐项检查点、线、面、体、符号、色彩、字体与文字分别承载何种语义；区分数据编码、导航编码、解释性图像和纯装饰。检查尺寸/面积/体积是否有真实比例依据。

## D｜数据／信息架构
还原源数据表：一行代表什么、一列代表什么；记录唯一 ID、组织键、分组字段、关联键、来源和单位。若原始数据不可得，标注为“依据图面反向推测的数据结构”。

## E｜视觉叙事架构
记录阅读入口、主视觉锚点、信息展开顺序、主证据、辅助解释、结论与注释；总结读者如何从整体进入局部并完成理解。

## 2026-11-23｜CASE-71与CASE-72案例归纳
- [CASE-71｜MARKETING人物轮廓造型词云](./案例/CASE-71-MARKETING-人物轮廓词云/分析.md)：同一词语重复、旋转与轮廓填充；偏概念海报，**不是经核验的词频统计**。
- [CASE-72｜INNOVATION关键词词云](./案例/CASE-72-INNOVATION-关键词权重词云/分析.md)：多词项并列，字号建立视觉层级，红色中心词引导非线性扫描；真实词频与权重未知。

### 共性与边界
- **数据逻辑：** 词项作为独立元素并列分布，主归属04字母表型；视觉上有大字不等于存在单向层级型数据逻辑。
- **统计：** 必须区分有语料支持的统计词云和仅靠人工字号编排的概念词云。
- **编码：** 字号、字重、旋转、位置、色彩、密度、轮廓；无图例或数据时，不能将字号与色彩认作精确数值。
- **叙事：** 先识别最大词或整体造型，再扫描次级词与局部细节，支持跳读。
- **制作：** 语料清洗/词频（若有）→ 字号映射 → 轮廓/画布约束 → 自动或人工排布 → 碰撞检查 → 色彩优化 → 核验归档。
