# 04｜统计图形分析

本目录研究信息图形案例借用的统计图形及其数据要求。它不取代 01 的五大基础信息组织逻辑，也不把“图表外观”当作信息图形主类型。

## 每种统计图形的研究字段
1. 图表名称与变体；2. 解决的问题；3. 输入数据结构（观测单位、维度、度量）；4. 数据转换与聚合；5. 统计计算与公式；6. 视觉通道（位置、长度、角度、面积、颜色、形状）；7. 轴、单位、分母和尺度；8. 适用场景与限制；9. 易错用法；10. 相关案例链接。

## 建议的统计图形研究目录
- 比较：条形图、点图、哑铃图、坡度图
- 时间：折线图、面积图、时间区间图、甘特图
- 分布：直方图、箱线图、密度图、散点图
- 构成：饼/环图、堆叠条、树图、旭日图
- 关系：散点图、气泡图、网络图、弦图
- 地理：分级设色图、比例符号地图、流向图、格网图
- 多变量：热力矩阵、平行坐标、小倍数图

以上是研究目录建议，不代表这些图表已完成分析。每种图表应单独建立说明文档，按真实数据结构和计算方式补充。
