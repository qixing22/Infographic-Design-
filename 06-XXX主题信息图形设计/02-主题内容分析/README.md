# 02 主题内容分析

## 与大模型共同分析

提供选题、已有材料、候选字段和目标读者，请大模型说明数据关系、给出分类理由，并指出还缺哪些证据。记录讨论过程和最终判断。

| 判断维度 | 需要回答的问题 |
| --- | --- |
| 数据逻辑 | 时间顺序是否主导阅读（编年型）？是否同时具有编年关系和单向、不可逆的层级顺序（编目型）？也可对照层级型、字母表型和地理图形。 |
| 视觉风格 | 平面图形还是照片更适合表现对象、场景和证据？ |
| 表现标签 | 词云图、文字型信息图、照片型信息图等，分别承担什么信息表达任务？确定主标签和辅助标签。 |

可直接提问：根据这些资料和字段，判断主导的数据组织逻辑，给出依据。再提出两种视觉风格和合适的表现标签，说明各自适用的内容。
