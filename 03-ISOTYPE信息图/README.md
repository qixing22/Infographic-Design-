# 03｜ISO信息图（ISOTYPE）

ISOTYPE（International System of Typographic Picture Education）是一种基础的信息图形设计方法，可用于不同数据组织逻辑和不同表现形式的案例。

## 图符如何表达数量

1. **统一图符**。同一种对象使用形状和大小一致的图符。
2. **定义单位**。用图例明确一个图符代表多少，例如「每个图符代表 100 人」。
3. **重复与对齐**。用图符的个数表达数量，按组排列并对齐起点，方便比较。

例如，甲社区有 300 人，乙社区有 500 人。按每个图符代表 100 人绘制，甲排列 3 个图符，乙排列 5 个图符。
