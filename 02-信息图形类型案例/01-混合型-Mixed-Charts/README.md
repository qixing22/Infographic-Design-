# 混合型信息图形（Mixed Charts）

> 文档状态：分类说明框架；等待用户提供案例图后归纳定论。

## 当前工作定义（待案例验证）
本项目将重点考察这样一类信息图形：它不止于把多个统计图形并置，而是对统计图形进行视觉叙事与视觉编码，并可能结合符号、ISO 图形和统计图形共同组织信息。此描述来自当前项目分类要求，具体边界仍需由案例分析确定。

## 案例分析维度
1. **数据逻辑**：包含哪些数据类型、变量、维度和关系；不同图形是否共享数据或表达不同子集。
2. **统计图形**：使用了哪些统计图形；每种图形的统计口径、计算方式和适用范围。
3. **视觉编码**：点、线、面、体、符号、ISO 图形、色彩、尺寸、方向、纹理如何共同编码。
4. **信息架构**：图表、图例、注释、标题、标签和说明之间如何组织。
5. **视觉叙事**：信息如何排序、比较、关联、强调，并引导读者得出结论。
6. **混合机制**：不同图形之间是叠加、拼接、嵌套、映射还是互补；组合是否产生单一图表无法完成的表达。

## 需要从案例中验证的问题
- “混合”是统计图形类型的混合，还是统计图形与符号/ISO 图形的混合，或两者兼有？
- 图形组合是否由同一套数据逻辑驱动？
- 视觉叙事是否改变了统计图形原本的阅读顺序？
- 哪些编码是定量编码，哪些是分类或装饰性编码？
