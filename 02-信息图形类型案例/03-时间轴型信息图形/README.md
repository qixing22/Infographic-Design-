# 时间轴型信息图形（Timeline Infographics）

> 文档状态：分类说明框架；等待用户提供案例图后归纳定论。

## 当前分析范围（待案例验证）
本类重点收集以时间轴为主要组织线索的信息图形。需在案例中辨别时间轴是单纯排列事件，还是进一步表达持续时间、阶段、并行事件、因果关系、变化趋势或多条时间线。

## 案例分析维度
1. **时间数据**：日期、时间点、时间区间、持续时长、时间粒度和精度。
2. **事件关系**：先后、并行、包含、重复、阶段、因果或转折。
3. **轴线结构**：水平/垂直/环形/分支时间轴，单线或多线，是否有断轴或尺度变化。
4. **视觉编码**：节点、连线、区间色块、符号、图标、色彩、字号和标注。
5. **信息架构**：事件标题、描述、时间标签、分类、来源及其层级。
6. **视觉叙事**：时间推进方向、重点节点、节奏、转折、高潮与结尾。

## 需要从案例中验证的问题
- 时间轴是否按真实时间比例绘制，还是仅按顺序等距排列？
- 节点表示瞬时事件还是持续区间？
- 多条时间线如何区分并保持可比较性？
- 视觉强调是否会夸大时间间隔或事件重要性？
