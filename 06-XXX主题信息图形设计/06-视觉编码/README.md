# 06 视觉编码

根据叙事任务记录「数据字段 → 视觉形式 → 读者看到的关系」。

- 点、线、面、体用于表达位置、路径、区域或立体结构。
- 色彩用于区分类别、表达数值梯度或建立主次。
- 行距、字距和字号用于组织文字层级与阅读节奏。
- 图像、图形和统计图形按证据展示、对象识别或数据比较的需要选取。
- ISO 图形（ISOTYPE）记录图符代表的对象、单个图符的数量单位和排列方式。
